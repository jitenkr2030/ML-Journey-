
# Google Search Console Setup for reconcileai.in

## Step 1: Add Property
1. Go to: https://search.google.com/search-console
2. Click "Add Property"
3. Choose "URL prefix"
4. Enter: https://reconcileai.in/
5. Verify via HTML tag (already in meta) or DNS TXT record

## Step 2: Submit Sitemap
1. In GSC → Sitemaps
2. Enter: https://reconcileai.in/sitemap.xml
3. Click "Submit"

## Step 3: Request Indexing (IMPORTANT!)
1. In GSC → URL Inspection
2. Enter each URL and click "Request Indexing":
   - https://reconcileai.in/
   - https://reconcileai.in/tools
   - https://reconcileai.in/blog
   - https://reconcileai.in/templates
   - https://reconcileai.in/extensions
   - https://reconcileai.in/blog/gst-reconciliation-process-guide
   (and every other important page!)

## Step 4: Set Preferred Domain
1. GSC → Settings → Ownership
2. Make sure https://reconcileai.in/ is the primary
3. Add reconcileai.de.deplexo.com as secondary (or ignore it)

## Step 5: Monitor
- Check "Coverage" report weekly
- Fix any "Excluded" or "Error" pages
- Monitor "Performance" for search queries
