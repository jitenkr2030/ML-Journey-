Income Tax Calculator — FAQ

Which regime is better for me?
The New Regime (default) is better if you have fewer deductions. The Old Regime is better if you claim HRA, 80C, 80D, home loan interest, and other deductions totaling more than ₹4-5 lakhs. Use this calculator to compare both instantly.
What is standard deduction in the new regime?
The standard deduction in the New Regime is ₹75,000 (increased from ₹50,000 in Budget 2024). In the Old Regime, it remains ₹50,000. This is automatically deducted from salary income.
What is rebate u/s 87A?
New Regime: Tax rebate up to ₹25,000 if taxable income ≤ ₹7,00,000 (effectively zero tax).
Old Regime: Tax rebate up to ₹12,500 if taxable income ≤ ₹5,00,000.
